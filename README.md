# Interactive 3D Bike Mechanics

A web-based interactive 3D bike mechanics learning platform built with React, Three.js, and Vite.

## Live Demo

**Website:** https://mounesh-13.github.io/interactive-3d-bike-mechanics/

## Features

- **3D Bike Model** - Interactive 3D visualization of bike components
- **Parts Guide** - Detailed information about each bike part
- **Troubleshooter** - Diagnose common bike issues
- **Physics Simulations** - Understand the physics behind bike mechanics
- **Engine Cycle** - Learn about internal combustion engines
- **Transmission System** - Explore gear systems
- **Maintenance Guide** - Step-by-step maintenance procedures
- **Quiz** - Test your knowledge

## Tech Stack

- React 19
- Three.js / React Three Fiber
- Vite
- Tailwind CSS
- TypeScript

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

The site is automatically deployed to GitHub Pages via the `gh-pages` branch.

```bash
# Manual deploy (if needed)
npm run build
npx gh-pages -d dist
```
